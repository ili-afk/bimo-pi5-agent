# BIMO — мой домашний AI-агент на Raspberry Pi 5

Привет. Меня зовут **Илья**, мне **16**, я из Москвы, и это мой проект.

**BIMO** — это AI-агент, который живёт у меня дома на обычном Linux-компьютере (Raspberry Pi 5
или б/у мини-ПК). Он умеет разговаривать голосом, писать и запускать код, делать 3D-модели
и управлять моим ПК. Идея простая: я не хочу каждый месяц платить за облако и не хочу, чтобы
всё зависело от чужого сервера. Поэтому агент — мой, локальный, а большая модель подключается
только когда реально нужна.

> Этот репозиторий — вся моя работа по проекту: планы, исследования, архитектура и облачная
> часть. Я собрал сюда всё, чтобы не потерять и чтобы другие могли повторить.

---

## Как я к этому пришёл

Сначала я хотел сделать **карманного «Джарвиса»** на ESP32-S3. Маленькая плата, копеечная,
влезает в корпус от старой колонки. Красиво.

Потом я упёрся в стену: на ESP32 **нет русских моделей** для кодового слова — то есть «Джарвис»
по имени он не отзывается. Плюс микроконтроллер физически не тянет нормальную модель, только
облако, а без интернета он вообще ничего не может.

Тогда я посмотрел на проект **brenpoly** (мужик сделал BMO на Raspberry Pi 5) и понял: мне нужен
не карманный терминал, а **нормальный компьютер с агентом**. Так проект и переехал с ESP32 на
Linux. Название BIMO осталось от того самого робота.

Карманный вариант я не выкинул — он живёт отдельно как проект [Jarvis](https://github.com/ili-afk/jarvis-ai-agent).

## Как это устроено

Простая схема: **дешёвый хост + умный «мозг» снаружи**.

```
   ┌──────────── МОЙ ДОМ (Linux: Pi 5 / мини-ПК) ─────────────┐
   │  микрофон → распознавание речи → ЯДРО АГЕНТА → динамик     │
   │  (кодовое слово, VAD, перебивание)                        │
   │  инструменты: файлы, терминал, браузер, код, 3D, зрение    │
   │  память (SQLite), шлюз в Telegram, доступ через Tailscale  │
   └───────────────────────────┬──────────────────────────────┘
                               │
                 ┌─────────────┴─────────────┐
                 ▼                           ▼
        локальная модель              облако (Cloudflare Worker)
        (Ollama, для простого)        (NVIDIA/OpenRouter — для тяжёлого)
```

Главная мысль: хост может быть слабым (4–8 ГБ), потому что саму модель он не крутит. Дорогую
память для «мозга» я уже имею — это мой обычный ПК.

### Слои

| Что | Чем делаю | Где |
|---|---|---|
| Кодовое слово | openWakeWord / sherpa (любая фраза) | хост |
| Распознавание речи | faster-whisper локально, Groq в облаке | хост / облако |
| Модель (мозг) | Ollama локально, NVIDIA/OpenRouter в облаке | ПК / облако |
| Голос (синтез) | Piper / edge-tts | хост / облако |
| Инструменты | файлы, терминал, браузер, код, 3D, MCP | хост + ПК |
| Память | SQLite + поиск | хост |
| Управление ПК | `computer_use` (MCP) + SSH | ПК |
| Удалённый доступ | Tailscale (никаких публичных туннелей!) | везде |

## Железо

| Что | Зачем |
|---|---|
| Raspberry Pi 5 8 ГБ **или** б/у мини-ПК с 16 ГБ | сам агент |
| NVMe-накопитель или нормальная microSD | система и модели |
| БП + охлаждение | питание и тепло |
| микрофон + динамик | голос |

Я долго охотился за ценами на Авито. Коротко: Pi 5 8 ГБ в Москве стоит 23 000–25 000 ₽, а б/у
мини-ПК с 16 ГБ памяти — часто **дешевле**. Всё потому, что в 2026 году сильно подорожала
оперативная память. Поэтому мой выбор — скорее б/у x86, а не новый Pi.

Подробности и живые лоты — в `docs/` (файлы про Авито и Pi 5).

## Облачная часть — папка `proxy/`

Это мой **Cloudflare Worker**: реверс-прокси, который умеет HTTP, стриминг (SSE) и WebSocket,
чистит заголовки и пускает только с токеном. Один файл, без зависимостей, бесплатный тариф.

Зачем: край Cloudflare доступен из России, а `workbuddy.ai` — нет (у части провайдеров). Прокси
делает запрос со своей стороны, поэтому у меня всё открывается **без VPN**.

## Что дальше

1. Купить хост (мини-ПК с 16 ГБ) и поставить Linux.
2. Написать первую версию агента — чтобы он просто отвечал голосом.
3. Поднять локальные шлюзы к моделям.
4. Добавить инструменты (код, 3D, управление ПК).
5. Сделать доступ с телефона через Tailscale.

Каждый шаг заканчивается чем-то **работающим**, а не «почти готово».

## Ограничения (чтобы не было сюрпризов)

- **В игры через агента поиграть не выйдет.** Управление ПК работает через «дерево доступности»,
  а игры его не дают. Только стриминг (Moonlight/Sunshine) + геймпад.
- **Агент нельзя выставлять в интернет.** Это дыра в безопасности. Только Tailscale.
- **Прокси не обходит проверку WorkBuddy** — он решает только доступ по сети. Для самого
  приложения нужен его встроенный туннель.
