# BIMO — персональный AI-агент на базе Raspberry Pi 5

> **EN:** BIMO is a personal, self-hosted **AI agent** running on Linux (Raspberry Pi 5 or a
> cheap x86 mini-PC). It combines a **voice interface** (wake word → STT → LLM → TTS) with
> **tools** (code, 3D modelling, web) and **remote PC control** (MCP `computer_use` + SSH).
> The LLM runs **locally or in the cloud** through a hybrid router; the cloud half is a
> Cloudflare Worker that also gives access to models **without a VPN** from Russia.
> Cloud budget: **0 ₽/month**.

BIMO — это домашний **AI-агент**: он разговаривает по-русски, пишет и запускает код,
делает 3D-модели, управляет ПК и живёт на обычном Linux-компьютере. Это прямой наследник
проекта «Джарвис»: тот оптимизировался под карманный ESP32-терминал, BIMO же — полноценный
**Linux-компьютер с агентом**, где голос — лишь один из интерфейсов.

| Железо | ESP32-S3, ~3 000 ₽ | Raspberry Pi 5 8–16 ГБ **или** б/у x86-мини-ПК, ~15 000 ₽ |
| Голос | единственный интерфейс | один из интерфейсов |
| Локальность | нет (нужен интернет) | **есть (офлайн-модель)** |
| Задачи | диалог, управление ПК | код, 3D, управление ПК, диалог, мессенджеры |

**Сохраняется:** русский язык, бесплатность (0 ₽/мес), Cloudflare Worker как облачная половина,
конечный автомат/WARMUP, алиасы инструментов, Tailscale вместо проброса портов.
**Отброшено:** ESP32, карманный корпус, батарея, OLED, донор «Яндекс Станции».

## Ключевое решение: «тонкий хост + вынесенный мозг»

Рост цен на память в 2026 сделал Pi 5 16 ГБ (распаянная LPDDR4X) экономически невыгодным.
Главный ход — **развязать LLM и хост**: хост остаётся тонким и дешёвым (4–8 ГБ), а «мозг»
уезжает на **уже имеющийся Windows-ПК** и/или в **облако**.

```
TIER 1 — тонкий хост (4–8 ГБ, 5–15 Вт)      TIER 2 — «мозг» (по запросу)
  wake word · VAD · ASR · TTS                  • Windows-ПК: Ollama, крупные модели
  инструменты · память · шлюз · Tailscale      • Cloudflare Worker → NVIDIA/OpenRouter
                          ◄── LAN / Tailscale ──►  • VseGPT.ru (резерв)
```

Требование к RAM у хоста падает с 16 ГБ до ~4 ГБ. Спайк цен перестаёт определять выбор платформы.

## Железо

| Позиция | Роль |
|---|---|
| Raspberry Pi 5 8 ГБ **или** б/у x86-мини-ПК / SFF / ноутбук | хост агента |
| NVMe (HAT/SSD) или A2 High-Endurance microSD | накопитель |
| БП 5 В/5 А (27 Вт) + активное охлаждение | питание / охлаждение |
| USB-микрофон + динамик | голос |

**Реальный диапазон** «мини-ПК с 16 ГБ под хост BIMO» — **15 000–26 000 ₽** (Авито, 08.10.2026).
Pi 5 8 ГБ в Москве — 23 000–25 000 ₽; б/у x86 с 16 ГБ часто **выгоднее**. Смета и лоты — в
документах [`docs/17`](docs/) и [`docs/Авито …`](docs/).

## Облачная половина: `proxy/` (Cloudflare Worker)

`cf-proxy` — реверс-прокси на Cloudflare Workers: решает **сетевую доступность** моделей и
`workbuddy.ai` из РФ **без VPN** (запрос делает край Cloudflare, а не ваш хост). Разворачивается
бесплатно на `*.workers.dev`. Код — в [`proxy/`](proxy/).

## Ограничения (важно)

- **Игры через `computer_use` не работают** — он опирается на дерево доступности; игры его не
  предоставляют. Только Moonlight/Sunshine + геймпад.
- **Публичный доступ к агенту = RCE.** Только Tailscale/WireGuard, никаких публичных туннелей.
- **Прокси не обходит** серверный детект WorkBuddy по телеметрии (`11128`/`11140`) — решает
  только сеть. Для приложения — его встроенный туннель.
