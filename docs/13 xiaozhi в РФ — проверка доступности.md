# 13 xiaozhi в РФ — проверка доступности

← [[Джарвис — карта проекта]]

Проверено 04.10.2026 **живыми запросами** с этой машины (Москва) и через внешний
DNS-резолвер Cloudflare (чтобы исключить влияние локального AdGuard).

---

## Короткий ответ

**Официальное облако `xiaozhi.me` из России технически доступно — сайт отвечает.
Но никакой «русской инфраструктуры» xiaozhi не существует: домены, на которые
ссылается русская адаптация, не резолвятся вообще.**

Итог: **либо самохостинг сервера, либо аккаунт на xiaozhi.me** (регистрация —
отдельный вопрос, см. ниже).

## Русская адаптация: что это такое

Найден репозиторий **`github.com/ZDarow/xiaozhi-esp32`**, ветка по умолчанию
`feature/russia-adaptation` (создан 11.09.2026, активно обновлялся **04.10.2026**).
README полностью на русском, есть русская документация.

Что в нём прописано по умолчанию (`main/Kconfig.projbuild`):

```
CONFIG_OTA_URL               = https://ota.xiaozhi.ru/xiaozhi/ota/
CONFIG_MQTT_DEFAULT_ENDPOINT = mqtt.xiaozhi.ru
CONFIG_WEBSOCKET_DEFAULT_ENDPOINT = wss://ws.xiaozhi.ru
```

**Проблема: все три хоста не существуют (NXDOMAIN).** Причём README честно
предупреждает об этом:

> «Важно на 04.10.2026: домен `ota.xiaozhi.ru` не существует в DNS
> (проверено через внешний резолвер: NXDOMAIN), поэтому прошивка со стандартным
> адресом не сможет проверить обновления. Задайте рабочий адрес при provisioning —
> NVS-ключом `ota_url` либо смените `CONFIG_OTA_URL` при сборке.»

Плюс в README указан адрес поддержки `support@xiaozhi.ru`.

**Следствие:** даже если прошить эту адаптацию, **она не заработает «из коробки»** —
адрес сервера всё равно придётся задавать свой. То есть русская адаптация экономит
перевод и правки кода, но **не решает вопрос хостинга**.

> ⚠️ Репозиторий молодой (0 звёзд, создан 11.09.2026) и ведётся агрессивно —
> дефолтные ветки переименовывались, был merge с веткой от `qwen.ai[bot]`,
> который автор отклонил. **Относиться как к чужому свежему коду**: прочитать
> `agent`/`main` перед прошивкой, не доверять слепо (то же предупреждение,
> что даёт brenpoly).

## Регистрация на xiaozhi.me

| Факт | Статус |
|---|---|
| Сайт открывается из РФ | ✅ проверено |
| В справке фигурирует **привязка номера телефона** (`绑定手机号`) | ✅ из официальной справки |
| Адрес поддержки | `xiaozhi.ai@tenclass.com` |
| Принимает ли **российский** номер телефона | ❓ **не проверено** |
| Есть ли MCP-точка на **бесплатном** тарифе | ❓ **не проверено** |
| Качество русского ASR/TTS в облаке | ❓ **не проверено** |

Документация самого проекта ранее писала: «если не открывается — нужен VPN».
Сейчас сайт открывается без VPN, но это не гарантирует, что пройдёт регистрация
(типовая проблема — SMS на не-китайский номер).

## Про «русский язык в xiaozhi»

На стороннем сайте `xiaozhi.dev/ru/` заявлено «Многоязычное ASR (КН/АН/ЯП/КР/РУ)»,
то есть русский среди языков распознавания.

**Но:** это **не официальный сайт** проекта, и в той же таблице «метрик
производительности» точность распознавания указана как «**точность распознавания
китайского языка**». То есть заявление о русском — маркетинговое и **не подтверждено
ни замером, ни документацией официального репозитория**.

В официальном README `78/xiaozhi-esp32` про русский ASR/TTS **не сказано ничего**;
упоминаются 39 языков **интерфейса** (подписи, подсказки), а не распознавания.

**Вывод: русский ASR в xiaozhi — не подтверждён. Считать его отсутствующим,
пока не проверено на живом устройстве.**

## Что это значит для проекта

| Вопрос | Ответ |
|---|---|
| Работает ли xiaozhi в РФ? | **Частично.** Сайт открывается, но русской инфраструктуры нет |
| Можно ли прошить и сразу говорить? | **Нет** — адрес сервера всё равно свой |
| Есть ли русское кодовое слово? | **Нет** (WakeNet/MultiNet — только cn/en) |
| Есть ли русский ASR в облаке? | **Не подтверждён** |
| Где хостить? | **Свой сервер** (ПК / Oracle) либо аккаунт xiaozhi.me |

**Это подтверждает вывод аудита (A1, A6):** «облачный xiaozhi.me из коробки» —
не рабочий путь для русского проекта. Правильный путь остаётся тем же:
**свой сервер + свои ASR/TTS** (см. [[04 Архитектура v2 — реалистичная]]).

## Что проверить вручную (5 минут, до покупки железа)

1. Зарегистрироваться на `xiaozhi.me` **с российского номера** — пройдёт ли SMS.
2. Найти в консоли раздел **«точка подключения MCP»** и проверить, доступен ли он
   на бесплатном тарифе.
3. Поговорить с устройством по-русски (если есть доступ к чужому/готовому) и оценить ASR/TTS.
4. Посмотреть `support@xiaozhi.ru` — отвечает ли адрес вообще.
