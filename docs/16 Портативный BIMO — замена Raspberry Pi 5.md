# 16. Портативный BIMO: чем заменить Raspberry Pi 5

← [[BIMO — консолидация и план миграции v1]]

**Задача:** собрать робота в стиле BMO, который можно брать в дорогу.
**Проблема:** Raspberry Pi 5 слишком дорогая.
**Дата проверки цен:** 08.10.2026, живые объявления Авито (101 + 111 позиций по трём проходам).

---

## 0. TL;DR

1. **Pi 5 в портативной сборке не нужна вообще.** Архитектура BIMO уже вынесла «мозг» в облако
   (Cloudflare Worker) или на домашний ПК. Устройству остаётся: wake word, захват и вывод звука,
   отрисовка экрана, сеть. Это по силам плате за **500–900 ₽**.
2. **Разница в цене — 25–50 раз.** Pi 5 8 ГБ в Москве = **23 000–25 000 ₽**.
   ESP32-S3 N16R8 = **500–900 ₽**. Orange Pi Zero 2W = **3 000–4 400 ₽**.
3. **Экран «как у BIMO» воспроизводится.** Вариант с Pi 5 (5″ DSI/HDMI) заменяется либо
   готовой HMI-панелью на **ESP32-P4-C6 с 4.3″–7″ IPS-тачскрином (4 000–7 000 ₽)**,
   либо Orange Pi Zero 2W + HDMI-экран.
4. **Функционал воспроизводится не полностью — и это нормально.** Полный Python-стек BIMO
   (faster-whisper, Piper, инструменты, SQLite) требует Linux. Микроконтроллер его не запустит,
   но при облачном «мозге» он и не нужен.
5. **Рекомендация:**
   - максимум похожести на BIMO за минимум денег → **ESP32-P4-C6 HMI 4.3″ — 4 000 ₽**;
   - «чтобы работал тот же код, что на BIMO» → **Orange Pi Zero 2W 2–4 ГБ — 3 000–4 400 ₽**;
   - «чтобы вообще без сюрпризов» → **б/у Raspberry Pi 4B 4 ГБ — 5 000 ₽**.

## 1. Почему Pi 5 в портативе не обязательна

Из `BIMO — консолидация и план миграции v1.md`, раздел 3:

| Компонент | RAM | Можно ли убрать с устройства |
|---|---|---|
| ОС + сеть + Tailscale | 0,5–1 ГБ | нет |
| faster-whisper `small` | 1–1,5 ГБ | **да → Groq (облако)** |
| Piper TTS | 0,2–0,5 ГБ | нет |
| Wake word | 0,2–0,5 ГБ | нет |
| Шлюз + память | 0,4–1 ГБ | нет |
| **Ollama + Gemma 3 2B** | **2,5–4 ГБ** | **да → облако / домашний ПК** |

**Вывод:** без локальной LLM устройству хватает **1–2 ГБ** — и это уже территория
микроконтроллера с PSRAM или дешёвого Linux-SBC. Pi 5 16 ГБ была нужна **только** под
локальный «мозг», а от него проект уже отказался.

Это ровно тот же ход, что и в миграции хоста: **не искать плату подороже, а снять с неё нагрузку.**

## 3. Три пути сборки

### Путь A. ESP32-S3 — «карманный BIMO» за ~2 500–3 500 ₽

| Позиция | Цена |
|---|---|
| ESP32-S3 N16R8 | 500–900 ₽ |
| Экран 2,8″ SPI 240×320 | 590 ₽ |
| Микрофон I2S (INMP441) | ~150 ₽ |
| Усилитель MAX98357A + динамик | 650 ₽ |
| 18650 ×2 + TP4056 | ~460 ₽ |
| Корпус | 300 ₽ |
| **Итого** | **~2 650–3 050 ₽** |

**Плюсы:** в 8–9 раз дешевле Pi 5; карманный формат; автономность реальная (потребление единицы ватт);
готовая прошивка `xiaozhi-esp32` — она уже разбиралась в проекте (документ 13).
**Минусы:** экран максимум ~3,5″ по SPI и с невысоким FPS; Linux нет; локальных ASR/LLM нет —
только облако; Python-стек BIMO не запустить.

### Путь B. ESP32-P4 + HMI-панель — «экран как у BIMO» за ~5 000 ₽ ⭐

| Позиция | Цена |
|---|---|
| ESP32-P4-C6 IoT HMI 4.3″ IPS тач (плата + экран + корпус) | 4 000 ₽ |
| Аккумулятор 18650 ×2 + TP4056 | ~460 ₽ |
| Динамик + усилитель | ~700 ₽ |
| **Итого** | **~5 160 ₽** |

**Плюсы:** **MIPI-DSI** — экран 4,3″/5″/7″ с нормальным FPS и ёмкостным тачем, то есть
визуально это ближе всего к BIMO; панель идёт готовой (не надо паять дисплей);
LVGL для анимации лица; есть варианты с камерой (+2 000 ₽).
**Минусы:** ESP32-P4 без Wi-Fi — в комплекте идёт ESP32-C6 как сетевой сопроцессор
(это отражено в названии «-C6»); Linux нет; локальных ASR/LLM нет.

### Путь C. Orange Pi Zero 2W — «тот же код, что на BIMO» за ~4 500–6 000 ₽

| Позиция | Цена |
|---|---|
| Orange Pi Zero 2W 2–4 ГБ | 3 000–4 360 ₽ |
| Экран 3,5″ с тачем (или 5″ HDMI за 5 000 ₽) | 954 ₽ |
| Аккумулятор + плата заряда | ~460 ₽ |
| Микрофон + динамик USB | ~1 000 ₽ |
| **Итого** | **~5 400–6 800 ₽** |

**Плюсы:** **полноценный Linux** → весь стек BIMO переносится как есть (faster-whisper,
Piper, openWakeWord, Python, SQLite); Wi-Fi и BT на борту; quad Cortex-A53 @1,5 ГГц;
в 5–7 раз дешевле Pi 5.
**Минусы:** слабее Pi 5; софт/драйверы сырее; NVMe нет; экран подключается по HDMI или SPI,
а не DSI.

### Путь D (страховка). Б/у Raspberry Pi 4B 4 ГБ — 5 000 ₽

Тот же экосистема и тот же образ, что у BIMO: Raspberry Pi OS, Camera Module, DSI-экран,
все туториалы. 4 ГБ хватает на тонкий хост. В 4,6 раза дешевле Pi 5 8 ГБ.
**Когда брать:** если не хочется отлаживать незнакомое железо и важна совместимость.

## 4. Что реально воспроизводится, а что нет

| Компонент BIMO (brenpoly) | ESP32-S3 | ESP32-P4 | Orange Pi Zero 2W | Pi 4B |
|---|---|---|---|---|
| Экран-лицо 5″ с тачем | ⚠️ до 3,5″ SPI | ✅ **4,3–7″ MIPI** | ✅ HDMI 5″ | ✅ DSI/HDMI |
| Анимация лица | ✅ LVGL | ✅ LVGL | ✅ tkinter/PyGame | ✅ |
| Wake word на устройстве | ✅ | ✅ | ✅ | ✅ |
| Локальный ASR | ❌ облако | ❌ облако | ⚠️ tiny/small | ✅ small |
| Локальная LLM | ❌ | ❌ | ❌ | ⚠️ 1–2B |
| Облачный «мозг» (CF Worker) | ✅ | ✅ | ✅ | ✅ |
| TTS | ⚠️ поток MP3 | ⚠️ поток MP3 | ✅ Piper/edge-tts | ✅ |
| Камера | ✅ OV2640 | ✅ MIPI-CSI | ⚠️ USB | ✅ CSI |
| Кнопки | ✅ | ✅ | ✅ | ✅ |
| Батарея / автономность | ✅ 18650 | ✅ | ✅ | ✅ |
| **Python-стек BIMO целиком** | ❌ | ❌ | ✅ | ✅ |
| Серво (рука) | ✅ | ✅ | ✅ | ✅ |

**Как читать эту таблицу:**
- Если «такой же функционал» = **голосовой диалог с облачным мозгом + экран-лицо** →
  подходит даже ESP32 за 500 ₽.
- Если «такой же функционал» = **буквально тот же код и стек, что на BIMO** (инструменты,
  память, локальный ASR, 3D) → нужен Linux, то есть Orange Pi Zero 2W или Pi 4B.
- **Чего не будет нигде, кроме Pi 5:** локальной LLM 7–8B и запаса под тяжёлые задачи.
  Но это и не нужно: в дороге «мозг» всё равно в облаке.

## 5. Как это ложится в архитектуру проекта

Портативный робот — это **Tier 1**, который уже описан в плане миграции:

```
┌──────────────────────────┐        ┌───────────────────────────────┐
│ TIER 1 — портативный     │  Wi-Fi │ TIER 2 — «мозг»               │
│ ESP32-S3 / ESP32-P4 /    │◄──────►│ • Cloudflare Worker →         │
│ Orange Pi Zero 2W        │        │   NVIDIA / OpenRouter         │
│                          │        │ • домашний BIMO (Ollama)      │
│ wake word · микрофон ·   │        │ • Tailscale                   │
│ экран-лицо · динамик ·   │        └───────────────────────────────┘
│ батарея · кнопки         │
└──────────────────────────┘
```

Это ровно та связка «ESP32 + вычислитель вне устройства», которую
`BIMO — полный план v3.md` пометил как **«стала избыточной»**. Для стационарного BIMO
она действительно избыточна. Для **портативного** — это и есть решение: карманный
терминал + домашний/облачный мозг.

Требование исходного ТЗ, которое считалось снятым, снова выполнимо:
«пользователь может достать устройство из кармана в любом месте, сказать „…“ и получить
голосовой ответ». Именно под него и был отменён карманный «Джарвис» на ESP32-S3.

## 6. Ограничения, которые надо принять

1. **Без интернета портативный BIMO немой.** Микроконтроллер не умеет локальный ASR/LLM.
   Нужна раздача с телефона. Это плата за цену в 500 ₽ вместо 23 000 ₽.
2. **Офлайн-режим возможен только на Linux-варианте** (Orange Pi / Pi 4B) и только
   на моделях 1–2B — то есть «ум» будет заметно слабее.
3. **Микрофон и AEC.** Для перебивания (barge-in) нужен эхоподавление, а ему — опорный
   сигнал динамика. Одного INMP441 мало: нужен кодек ES8311/ES7210 (это уже отмечено
   в разборе ТЗ проекта).
4. **Питание ESP32-P4.** Панели 4,3″–7″ потребляют заметно больше ESP32-S3; на 18650
   автономность будет часами, а не сутками. Считать по факту.
5. **Китайские HMI-панели** — качество лотерейное, документация неровная. Проверять
   наличие примеров LVGL под конкретную ревизию.
6. **Аккумуляторы 18650** требуют платы защиты и нормальной зарядки — не экономить на TP4056.

не даёт ничего сверх — её преимущество (локальная LLM 7–8B) в дороге всё равно не используется.

## 8. Что проверить перед покупкой

1. **ESP32-P4: уточнить ревизию** и наличие рабочего примера LVGL + MIPI-DSI под неё.
2. **Проверить, что в комплекте идёт ESP32-C6** (у P4 нет своего Wi-Fi).
3. **Для Orange Pi Zero 2W:** объём RAM именно тот, что в описании (1 / 1,5 / 2 / 4 ГБ);
   наличие mini-HDMI.
4. **Аккумуляторы:** ёмкость и наличие защиты; проверить реальную ёмкость (частый обман).
5. **Кодек для AEC**, если нужен barge-in, а не push-to-talk.
