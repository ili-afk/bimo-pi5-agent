## 4. ✅ РЕШЕНО (10.10.2026)

| Вопрос | Решение |
|---|---|
| **Хост** | **Raspberry Pi 5** — малое потребление, чтобы можно было использовать **вне дома** |
| **Экран** | **Да, экран с лицом.** Лицо можно **скрыть** и показать нужную информацию (статус, погода и т.п.) |
| **Мозг** | Пока **только облако** (гибрид локально+облако — позже, т.к. дороже) |
| **Первый шаг** | **Готовить форк** (код), железо — параллельно |
| **Кодовое слово** | **«Бимо»** (пока; при необходимости проверим бенчмарком) |
| **Голос** | **Наработки brenpoly** — Piper + дообученный голос BMO |
| **Имя репозитория** | **`bimo-custom`** |
| **Экран (тип)** | Решу при покупке |
| **MVP v0.1** | **Сначала ровно как у автора**, потом начинаем изменять |
| **Telegram-бот** | Не нужен |
| **Репозиторий** | Публичный |
| **Корпус** | Пока без корпуса |

**Следствия:**
- Хост = Pi 5 → хватит **тонкого клиента** (локальные модели не обязательны, мозг в облаке).
- Экран двойного назначения: **лицо** (по умолчанию) + **информационный режим** (по запросу).
- «Только облако» снимает требование к RAM хоста → **Pi 5 8 ГБ достаточно** (16 ГБ не нужны).
- Нужен **интернет всегда** (без него работает только базовый сценарий).
