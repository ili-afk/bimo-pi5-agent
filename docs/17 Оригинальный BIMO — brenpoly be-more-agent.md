## 1. Что это

**Be More Agent** — «кастомный, offline-first AI-агент для Raspberry Pi». Он превращает
маленький компьютер в говорящего робота: слушает кодовое слово, распознаёт речь, «думает»
локальной моделью и отвечает синтезированным голосом — **на 100 % локально, без облака**.

Главная фишка: **лица**. На экране крутится анимация рожицы робота, которая меняется по состоянию
(слушает / думает / говорит / простаивает). Это и делает его «живым».

Это «чистый холст»: картинки лиц и звуки легко заменить на своего персонажа.

## 2. Конвейер (как проходит разговор)

```
[wake word] → [запись] → [распознавание речи] → [модель] → [синтез голоса] → [динамик]
     │                                                                          │
     └─────────────── лицо на экране меняется по состоянию ────────────────────┘
```

| Шаг | Чем сделано | Файл/движок |
|---|---|---|
| Кодовое слово | **OpenWakeWord** (модель `.onnx`, по умолчанию «Hey Jarvis») | `wakeword.onnx` |
| Распознавание речи | **Whisper.cpp** | `whisper.cpp/` |
| Мозг (модель) | **Ollama** (`gemma:2b` / `gemma3:1b`) | `agent.py` |
| Поиск в интернете | **DuckDuckGo** (когда модель не знает ответа) | — |
| Зрение | **Moondream** + камера Pi | `vision_model` |
| Синтез голоса | **Piper TTS** + **свой дообученный голос BMO** | `voices/bmo.onnx` |
| Лицо | PNG-последовательности по состояниям | `faces/[state]/` |
| Звуки | `.wav` по категориям, выбираются случайно | `sounds/[category]/` |

---

## 3. Состояния (лица)

Лицо меняется в зависимости от того, что делает агент:
`idle` (простаивает) · `listening` (слушает) · `thinking` (думает) · `speaking` (говорит) ·
`error` (ошибка) · `warmup` (прогрев при старте).

Плюс звуки: приветствие при старте, «думающий» фон, «я тебя услышал», звуки ошибки.

## 4. Структура репозитория

```
be-more-agent/
├── agent.py            # главный скрипт («мозг»)
├── setup.sh            # автоустановщик
├── wakeword.onnx       # модель кодового слова («ухо»)
├── config.json         # настройки (модели, промпт, железо)
├── chat_memory.json    # история диалога (память)
├── requirements.txt    # зависимости Python
├── whisper.cpp/        # движок распознавания речи
├── piper/              # движок синтеза + голоса
├── voices/             # кастомный голос BMO (bmo.onnx + .json)
├── sounds/             # звуки (greeting / thinking / ack / error)
└── faces/              # лица по состояниям (idle / listening / thinking / speaking / error / warmup)
```

## 5. Конфиг (`config.json`)

```json
{
  "text_model": "gemma3:1b",
  "vision_model": "moondream",
  "voice_model": "piper/en_GB-semaine-medium.onnx",
  "chat_memory": true,
  "camera_rotation": 0,
  "system_prompt_extras": "You are a helpful robot assistant. Keep responses short and cute."
}
```

Меняется без правки кода: модель, голос, промпт, память, поворот камеры.

## 6. Железо

- **Raspberry Pi 5** (рекомендуется) или **Pi 4 (минимум 4 ГБ RAM)**.
- USB-микрофон и динамик.
- Экран (DSI или HDMI) — для лица.
- Камера Raspberry Pi — для зрения.

## 7. Установка (коротко)

```bash
sudo apt update && sudo apt upgrade -y && sudo apt install git -y
curl -fsSL https://ollama.com/install.sh | sh
ollama pull gemma:2b
ollama pull moondream
git clone https://github.com/brenpoly/be-more-agent.git
cd be-more-agent && chmod +x setup.sh && ./setup.sh
source venv/bin/activate && python agent.py
```

`setup.sh` сам ставит библиотеки, скачивает Piper и голос BMO, создаёт папки и venv.

## 8. Чем оригинал отличается от нашего BIMO

| | Оригинал (brenpoly) | Наш BIMO |
|---|---|---|
| Модель | **локально** (Ollama, gemma 1–2B) | **гибрид**: локально + облако (для тяжёлого) |
| Язык | английский (по умолчанию) | **русский** с самого начала |
| Кодовое слово | своя `.onnx` модель (обучать) | sherpa (любая фраза, без обучения) |
| Управление ПК | нет | **есть** (computer_use + SSH) |
| Экран/лицо | **есть** (PNG-анимация) | пока нет (это надо взять у оригинала!) |
| Зрение | есть (Moondream + камера) | в планах |
| Код и 3D | нет | **есть** (через облако) |
| Хост | только Raspberry Pi | Pi 5 **или** б/у мини-ПК |

**Что забрать у оригинала:** анимация лица по состояниям, случайные звуки, WARMUP-прогрев модели,
идея «холста» для персонажа, дообученный голос.

## 9. Ограничения оригинала

- **Апстрим заморожен** (последний коммит 11.04.2026) — брать форки.
- **Локальная модель слабая** (gemma 1–2B) — сложные задачи ей не по силам.
- **Только английский** из коробки.
- Нужны **экран и камера** — это часть образа, без них теряется «лицо».
- Нет управления ПК и нет работы с кодом/3D.
